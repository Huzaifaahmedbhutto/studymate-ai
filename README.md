## 📌 What is StudyMate AI?

StudyMate AI is a free AI-powered learning platform built specifically for students. Whether you are preparing for exams, trying to understand a tough topic, or just want to study more efficiently — StudyMate AI has everything you need in one place.

Built by a 2nd year CS student, for students. No sign-up required. Completely free.

## 🚀 Getting Started

Want to run it locally? Follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/Huzaifaahmedbhutto/studymate-ai.git
cd studymate-ai
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Add your API keys
Create a `.env` file in the root folder and add:
```
ANTHROPIC_API_KEY=your_claude_api_key
GROQ_API_KEY=your_groq_api_key
```

### 4. Run the app
```bash
streamlit run study_agent.py
```

Then open your browser at `http://localhost:8501`
